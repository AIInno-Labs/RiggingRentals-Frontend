1. What this app is

A single-tenant equipment rental ERP for Rigging Rentals (Kenwick WA). It covers the yard hire path that Point of Rental / Sunbelt-style shops run daily:

  • Leads & quotes with customer PO
  • Hire T&Cs acceptance + credit checks before confirm
  • Workshop pick / cert check / dispatch
  • Delivery & pickup logistics with proof of delivery (signature)
  • Off-hire, return QC (dirty / damage / missing fees)
  • Finance draft â†’ approve â†’ send â†’ paid, plus Xero CSV export
  • Maintenance work orders and repair bay

8. Pitch tips & common blockers

Tell this story
  1. Lead in â†’ quote out (same day)
  2. No confirm without T&Cs + credit
  3. Serial + cert before it leaves the yard
  4. Signature on delivery
  5. Dirty/damage money lands on the invoice
  6. Finance closes with Xero-ready export
If something blocks
  • Confirm blocked â€” missing hire acceptance, On stop, over credit, or unpaid AR
  • Dispatch blocked â€” cert not ticked / expired cert (non-admin)
  • POD incomplete â€” signer name required
  • No draft invoice â€” finish return QC + mark returned
  • Invalid UUID (old build) â€” refresh after Zod guid fix for seed IDs

Not in this MVP (say so up front): live Xero API, customer self-serve accept link, card payments gateway, multi-branch transfers, telematics, DocuSign. Position as Phase 1 after a successful pilot.
